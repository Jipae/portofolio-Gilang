My Skills

Subnetting

Nggak cuma sekadar ngitung atau ngafal kelas IP (A, B, C). Saya paham cara memecah jaringan yang lebih besar jadi segmen-segmen kecil (VLSM) biar alokasi IP lebih efisien, nggak buang-buang host, dan broadcast domain-nya lebih terarah. Cocok buat manajemen IP di lab atau kantor.

Routing

Bukan cuma static routing yang input jalurnya manual satu-satu. Saya paham konsep dynamic routing kayak OSPF atau RIP. Jadi, kalau misalnya ada satu kabel atau jalur antar router yang putus, jaringannya bisa otomatis nyari jalan alternatif biar koneksi tetap jalan terus.

HTML

Paham cara bikin kerangka struktur halaman web. Buat anak TKJ, ini kepake banget pas lagi dapet project bikin halaman Login Hotspot (Captive Portal) di MikroTik atau bikin web profil sekolah sederhana.

CSS

JavaScript
